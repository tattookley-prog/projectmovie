## Описание

**Movie Library** — десктопное GUI-приложение на Python (tkinter) для хранения
и управления личной коллекцией фильмов.

### Возможности

| Функция | Описание |
|---|---|
| Добавление фильма | Заполните форму и нажмите «Добавить фильм» |
| Таблица фильмов | Все записи отображаются в виде сортируемой таблицы |
| Фильтрация | По жанру (подстрока) и/или по году выпуска |
| Удаление | Выберите строку → «Удалить выбранный» |
| Сортировка | Клик по заголовку столбца |
| Сохранение | Автоматически при каждом изменении (файл `movies.json`) |
| Валидация | Проверка всех полей перед сохранением |

## Требования

- Python **3.9+**
- Стандартная библиотека (tkinter входит в поставку Python)
- Для тестов: `pytest` (опционально)

```bash

```

## Примеры использования

### Добавление фильма

1. Введите: Название = `Inception`, Жанр = `Sci-Fi`, Год = `2010`, Рейтинг = `8.8`
2. Нажмите **➕ Добавить фильм**
3. Фильм появится в таблице и сохранится в `movies.json`

### Фильтрация

- Введите `sci` в поле «Жанр» → отобразятся все фантастические фильмы
- Введите `2010` в поле «Год» → только фильмы 2010 года
- Нажмите **↺ Сбросить** для возврата к полному списку

### Формат JSON

```json
[
  {
    "title": "Inception",
    "genre": "Sci-Fi",
    "year": 2010,
    "rating": 8.8
  },
  {
    "title": "Побег из Шоушенка",
    "genre": "Драма",
    "year": 1994,
    "rating": 9.3
  }
]
```
